# Chihuo 第一版范围

## 产品闭环

消费者发布需求 -> 需求聚合 -> 商家报价 -> 平台审核 -> 预售下单 -> 生产批次 -> 骑手配送 -> 售后与食品安全记录。

## 角色端

- 消费者小程序：需求广场、发布需求、加入需求、预售、订单、售后。
- 商家小程序：需求大厅、报价、商品、生产批次、订单、资质、食品安全事件。
- 骑手小程序：任务、取餐、配送、异常上报。
- 平台管理后台：资质审核、需求/商品审核、订单售后、事故处置、审计日志。

## 第一版不做

- 自建即时配送调度算法。
- 医疗诊断、疾病治疗或营养处方。
- 复杂的自动竞价和智能定价。
- 直播录像合规审查自动化。
- 微服务拆分和跨区域多租户。

## 验收原则

- 所有关键状态有明确的状态机。
- 用户可以看到订单和需求进度。
- 商家只能在平台审核后发布预售活动。
- 食品安全事件可以冻结相关商品和订单。
- 订单、退款、审核和事故操作有审计记录。
