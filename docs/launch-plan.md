# 第一版启动验证

## 建议范围

- 一个园区或社区。
- 一个用餐时间。
- 一到两个餐品品类。
- 三到五家商家。
- 五十到一百名种子消费者。

## 消费者侧

宣传重点是具体需求，不是抽象平台能力：

- “低油定量午餐需求征集”
- “满 20 人，商家按需求开做”
- “份量、配料和生产批次公开”

通过园区群、社区群、物业、便利店、本地生活社群和线下二维码收集种子用户。先验证付费意向，再扩大投放。

## 商家侧

宣传重点：

- 先看真实需求，再决定生产。
- 批量订单减少试错和库存。
- 平台协助完成规格、报价、批次和售后记录。

首批商家采用人工拜访和陪跑入驻，优先让商家完成两轮真实预售。

## 核心指标

- 需求发布到有效意向的转化率。
- 需求组达到生产阈值的比例。
- 商家报价响应率。
- 预售付款转化率。
- 准时交付率。
- 退款和食品安全投诉率。
- 消费者复购率。
- 商家连续参与轮次。
